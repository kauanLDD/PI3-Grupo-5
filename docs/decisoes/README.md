# Decisões

Uma decisão por arquivo, numerada na ordem em que foi tomada, com o nome `NNNN-assunto.md`.

Cada arquivo diz o contexto, a decisão, o motivo, e o que foi descartado. Número que entra
aqui é número medido, com o comando ou o script que mediu ao lado.

Decisão que mudou não se apaga: ganha o estado atualizado e o arquivo novo referencia o
antigo. Histórico apagado vira "sempre foi assim", e aí ninguém sabe se foi pensado.

Isto existe por causa da defesa. Quando perguntarem "por que vocês descartaram esses exames?"
ou "por que normalizaram assim?", a resposta está escrita com data, em vez de reconstruída de
memória na hora.
